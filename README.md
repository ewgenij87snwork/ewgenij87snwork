## About

I have 5+ years of commercial frontend experience, mainly with Angular and TypeScript. I have worked on enterprise real estate, white-label B2B products, graph and data-visualization tools, and Web3 products.

Most of that work was in existing codebases: understanding product rules, fixing data-flow and state problems, building forms and integrations, debugging, and shipping changes without rewriting everything around them.

My current independent projects also use NestJS, PostgreSQL/Prisma, React/Next.js, Docker, CI/CD, testing, and release work. I also maintain CLROOM, an open-source Rust tool for clean, selective Codex and Claude Code launches.
